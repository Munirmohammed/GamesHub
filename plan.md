# Games Suite Implementation Plan

This project aims to build a collection of premium, addictive 2D games designed for high engagement and monetization.

## 🚀 Game Roadmap

### 1. Game #1: Neon Drift (Current Focus)
*   **Concept**: Orbit-based physics avoid-em-up.
*   **Key Features**:
    *   One-touch controls.
    *   Dynamic neon visuals.
    *   Progression (Difficulty scaling).
    *   Satisfying feedback (haptics/visual juice).

### 2. Game #2: Quantum Leap
*   **Concept**: Gravity-shifting runner.
*   **Key Features**: High-speed, synthwave aesthetic.

### 3. Game #3: Zen Stack
*   **Concept**: Physics-based tower builder.
*   **Key Features**: Relaxing atmosphere, perfect-stack bonuses.

---

## 🛠️ Shared Infrastructure
*   **Framework**: Vite + Vanilla JS (for maximum performance and no bloat).
*   **Styling**: Shared "Premium" CSS design system (located in `/shared/styles`).
*   **State**: LocalStorage for high scores and unlocked content.
*   **Monetization Ready**: Placeholder for AdSense/AdMob integration.
